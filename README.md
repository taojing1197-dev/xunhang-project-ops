# xunhang-project-ops

A Codex skill for maintaining a multi-platform UniApp logistics product across H5, WeChat, Alipay, an admin application, API contracts, regression tests, and release preparation.

## Install

Copy this repository to your Codex skills directory, then start Codex in the project workspace. The skill routes changes through the project's own source tree, documentation, and tests.

## Safety

The workflow distinguishes source from generated builds and treats payments, wallets, customer isolation, database changes, and production deployment as high-risk operations.
